20261106_advance 已完成 6000 步。训练 CE 降至约 0.34，但验证 token CE 从 1.6133 升至 2.1275，固定监控仍为 14/60。原最终 2000 步与新最终 6000 步比较：

总分没有揭示任务之间的回退。原固定自然语言探针“请只回答：你好”在最初返回“你好”，最终却重复无关句子直至 48 token 上限；该样本的 token 4-gram 重复为 77.8%。固定 60 题 EOS 100% 不代表日常对话已无重复。

代码和数据检查确认：

- 三种措辞仅复用了原 12000 个程序参数案例，没有增加参数身份。9600 个字符串载荷各自只属于一种操作，缺少同载荷的复制、大小写、反转和计数对照。
- 公共样本占训练行约 25%，却占监督 token 的 90.15%；验证公共行也仅约 25%，却占监督 token 的 89.13%。训练按样本等权，旧 best 选择按 token CE，因此目标权重不一致。
- 算术留出的数字为 `n % 5 == 4`，原训练排除了这些数字。旧监控是未见操作数泛化，而非仅新题；本轮保留原隔离及门槛。

这些证据支持窄数据过拟合、操作混淆及部分遗忘；未发现优化器停止更新。执行提速没有解决这些质量问题。

## 新阶段安排

新数据将扩大真正不同的参数与载荷；同一字符串的五种操作和两种语言共享验证组，算术的同一操作数家族也共享验证组。字符串长度覆盖短串到长串。公共问答从原始 96024 条指令源重新选择，允许保留最长完整对话前缀，保留上下文、真实 EOS 和来源元数据。原 1200 条留出与 60 条监控逐字节保留，保留探针不进入训练。
