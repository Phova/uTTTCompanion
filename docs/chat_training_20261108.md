# 2026-11-08：日常对话优先的 1000 步试训

本轮保持 1,583,879,748 参数模型，目标是加强日常交流，同时检查基础推理和编程是否回退。它是一次独立的短程 SFT 试验，不能把训练损失下降直接解释为聊天质量改善。

## 数据

样本比例为日常对话 60%、基础推理 20%、编程 20%。共选择 12000 条，实际分为 11400 条训练和 600 条内部验证；另保留 600 条按内容家族隔离的留出样本。当前数据目录为远端 `/root/uTTT/data/chat_curriculum_20261108_final3/`，会话、问题和参数家族边界用于避免跨集合泄漏。

公共对话和代码经过启发式筛选及格式、完整性检查，尚未逐条完成事实或代码执行核验。6000 条生成的基础推理候选已做参考答案校验；实际选入的 2400 条推理数据是公共与生成样本的混合，不能称为全部经程序验证的合成题。来源、许可证和版权信息保留在源数据行及 manifest 中。

数据文件哈希、实际类别和语言分布、窗口一致性及 CPU 检查记录见 [chat_training_measurements_20261108.json](chat_training_measurements_20261108.json)。代码仓库只提交实现和聚合证据，不上传训练语料或模型权重。

## 初始化与训练设置

父权重采用 `uttt_1.584b_20261107_expand.best.pt` 第 2000 步。相同的新 40 题开发诊断中，它的回答重复较少，推理为 2/16；第 6000 步候选为 1/16，两者编程均为 0/12。这是小型开发集上的初始化选择依据，不能称第 2000 步模型全面更好。

新数据使用新 Adam 优化器，从权重初始化开始，不继承父阶段的优化器、步数或数据游标。配置为 `configs/5090_chat_20261108.yaml`：

- 目标 1000 步，序列长度 512；语义微批 B1、累积 16 条样本。
- 慢权重学习率 1e-5、W0 外循环学习率 5e-6，预热 100 步。
- BF16 混合精度，启用已在 `fce3b4b` 发布的共享 W0 只读 GEMM、步内合并、PAD32 和 1536 物理 token 分组上限。
- 每 250 步验证，每 500 步常规保存，按内部每样本 CE 记录 best；实际吞吐以本轮日志为准。

使用独立运行 `20261108_chat`，输出到远端 Windows C 盘：

`/mnt/c/uTTT-artifacts/checkpoints/20261108_chat/uttt_1.584b_20261108_chat.pt`

完整训练状态和 `.best.pt` 分别保存，已有模型和已完成运行不覆盖。

## 评测与阶段边界

新的 40 题开发集包含 12 道聊天题、16 道明确答案推理题和 12 道受限 Python 函数题。其中 4 道聊天题显式提供近期对话历史。聊天回答待人工审阅，不生成自动聊天质量分；推理严格匹配参考答案；编程通过受限 AST 解释器核对多组输入输出，不执行模型生成代码，也不将语法可解析视为程序正确。

训练前评估父模型，训练后以相同的无惩罚贪心设置、128 token 上限分别评估 best 和 final。任务内容、报告与检查点身份进入运行记录。该开发集用于比较和诊断，不能作为最终盲测；显式近期文本上下文也不能证明长期快权重记忆。

原有 60 题监控和至少 50% 正确率、改进及 EOS 保护门槛继续保留，不被新的开发集替换。开发集分项结果不会自动批准元训练、在线写入或服务模型替换。

本阶段 `surprise_aux_loss_weight=0`，动态快权重写入和在线写入关闭；W0 仍接受语言目标的外循环梯度。这属于语言 SFT 准备阶段，不等同于已经完成完整 uTTT 元训练或长期个性化记忆。
